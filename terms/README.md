# Terms

One folder per cohort. Everything belonging to a single run of the course — that
term's notes, assignments, project and submissions — lives in its own folder and
stays there.

Nothing is filed by term yet; this course has no archived material from previous
cohorts.

## Adding your term

```
terms/2026-2027-fall/
├── README.md      instructor, schedule, exam dates, whose work this is
├── assignments/
├── notes/
└── project/
```

Write the README first. A folder of files with no attribution is much less useful
to the next person than three lines saying who made it and when.

The shared plan in [`weeks/`](../weeks/) and the reference material in
[`docs/`](../docs/) stay general — improve those in place rather than copying them
into a term folder.
